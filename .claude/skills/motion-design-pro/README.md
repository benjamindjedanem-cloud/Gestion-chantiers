# Skill motion-design-pro

Goûts et méthode de motion design de Benjamin, construits à partir de ses vidéos de référence.

- Dans ce dépôt, Claude Code le charge automatiquement (`.claude/skills/`).
- Pour l'avoir dans **toutes** les conversations et tous les projets : l'importer sur claude.ai
  (Paramètres → Capacités → Skills → Importer) avec le zip généré ainsi :

```bash
cd .claude/skills && zip -r -q motion-design-pro.zip motion-design-pro -x '*/README.md'
```

Après chaque nouvelle référence, régénérer le zip et remplacer le skill sur claude.ai.

## Projet de référence

Gestion Chantiers (dépôt `Gestion-chantiers`, dossier `video/`) : brief, storyboard, images clés validées
(`video/style-frames/`), animation Remotion (`video/src/anim/`), voix off et effets sonores. Compositions :
`PromoCourte` (34,8 s, version préférée) et `Promo` (50,3 s, version expliquée).
