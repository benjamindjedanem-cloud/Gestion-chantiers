# Vidéo promo — Gestion Chantiers

Projet [Remotion](https://www.remotion.dev) (vidéo écrite en React) pour la vidéo de promotion de l'application.

- Format principal : 1080×1920 (9:16), 30 i/s — TikTok, LinkedIn, Facebook
- Identité visuelle : `src/theme.ts` (couleurs et polices reprises de l'application)

## Commandes

```bash
npm install
npm run studio   # aperçu interactif dans le navigateur
npm run render   # export MP4 dans out/
```

Dans l'environnement cloud, indiquer le Chromium préinstallé :

```bash
REMOTION_BROWSER=/opt/pw-browsers/chromium_headless_shell-1194/chrome-linux/headless_shell npm run render
```

Licence Remotion : gratuite pour un particulier ou une entreprise de 3 personnes maximum.
